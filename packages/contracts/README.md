# @sf/contracts

Contratos compartidos de la Software Factory: sobre de entrada de issues
(`IssueEnvelope`), estados de ejecucion, eventos de transicion, politica de
riesgo/presupuesto y paquete de evidencias.

Estado actual: **RED**. Los tests de `tests/` definen el contrato esperado; la
implementacion con Zod se escribirá en la fase GREEN tras aprobacion humana
(criterios de GEN-16, seccion 8).

Referencias:

- GEN-16, seccion 4 (arquitectura) y seccion 8 (reglas de ingenieria).
- `docs/architecture/` (pendiente de rellenar en fase F5).
